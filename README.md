# Тихие истории

Адаптивный frontend галереи коллекционных декоративных статуэток. Vite, модульный JavaScript и CSS; серверная часть не требуется.

## Запуск

```powershell
npm install
npm run dev
```

Адрес указан в терминале (обычно http://127.0.0.1:5173). `npm run build` создаёт production-версию в `dist`; `npm run preview` запускает её локально. Для публикации разместите содержимое `dist` на статическом хостинге. Навигация использует hash-маршруты и не требует настройки переадресаций.

## Каталог

Товары находятся в `src/products.js`, изображения — в `public/images`. Каждый товар содержит id, name, description, category, tags, price, images, additionalImages, material, height, width, condition, year, origin, available, featured, unique, isNew. `additionalImages` поддерживает отдельные фотографии и настройки позиции/увеличения для деталей. Чтобы добавить товар, добавьте объект в массив и его фотографии в public/images.

Все товары, цены, происхождение и изображения демонстрационные. Фотография-референс не была приложена: изображения созданы генеративно для этой концепции. Детали представлены увеличенными фрагментами; перед продажей замените их реальными отдельными макрофотографиями. Исходные PNG сохранены рядом с оптимизированными WebP.

## Возможности

Главная, коллекция, страницы товаров, истории, о бренде, избранное, корзина, информационные страницы. Поиск по названию с поддержкой е/ё, категории, максимальная цена, сортировка, новинки, уникальные экземпляры. Полноэкранная галерея с клавиатурой, свайпами и Escape. Избранное и корзина сохраняются в localStorage; в политике конфиденциальности доступна очистка. В корзину добавляется один экземпляр каждого произведения. Есть экспорт подборки в текстовый файл.

Оплата, отправка заказов и backend не подключены. Контакты, социальные сети и условия доставки не выдуманы — для них созданы страницы с объяснением текущего статуса. Перед открытием продаж заполните реальный каталог, контакты и условия, подключите сервис заказов. Шрифты загружаются с Google Fonts; при отсутствии сети используются системные serif/sans-serif.
